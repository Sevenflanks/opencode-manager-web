# Triage labels

| 角色 | GitHub label | 意義 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，且已授權 agent 自主執行 |
| `ready-for-human` | `ready-for-human` | 需要由人處理 |
| `wontfix` | `wontfix` | 決定不處理 |

使用 label 前確認遠端是否存在；保留既有同名 label，不覆蓋其設定。本文件定義名稱與語意，不會自動建立 labels 或變更任何 issue。
